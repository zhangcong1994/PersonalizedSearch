# exp-010 Phase 2 结果

> 实验目标：硬规则区 + 对比示例能否进一步压制逐篇罗列残存 + 修复准确性微跌
>
> 实验类型：Prompt 工程，单变量消融，纯文本改动，无训练
>
> 核心结论：**硬规则区导致全线崩溃，引文质量 −0.46，整合质量 −0.20，总分 −5.5。消融确认退化完全来自硬规则区，对比示例因被淹没而无法评估独立效果。**

## Phase 2 Prompt 改动

在 V1-full 基础上，设计了两项改动：

### 变量 A：硬规则区（~80 字）

将"### 避免以下行为"从 prompt 末尾提升到开头（角色设定后第一条），措辞从"不要"升级为"禁止"，新增"违反任一条则答案不合格"的后果声明，三条规则均附带补救指引：

- 禁止逐篇罗列 → "如果发现自己在按文档编号复述，停下来，合并后再写"
- 禁止编造 → "资料里没有的，就说不知道"
- 禁止元描述 → "不要出现「根据提供的资料」等套话，像人类一样说话"

连带影响：核心原则从详细展开压缩为每行一行（因为细粒度约束已由硬规则承担）。

### 变量 B：对比示例（~300 字）

在原有 2 个正面示例之间插入 1 个对比示例：同一个问题、同一批资料，先展示 ❌ 逐篇罗列的版本，标注"为什么错"，再展示 ✅ 合并整合的版本。示例的问题选型为手机配置查询——纯粹的多源信息拼合任务，让模型聚焦于"输出形式"的对比学习。

### 消融策略

回退了 3 个非预期改动后（整合步骤标题、矛盾输出模板、步骤 2 末尾的"不要重复出现"），Phase 2 有 3 个可测版本：

| 版本 | 内容 |
|------|------|
| v2 | V1-full + 硬规则区 + 对比示例 |
| v2-rules-only | V1-full + 仅硬规则区 |
| v2-contrast-only | V1-full + 仅对比示例 |

## 分析

### 发现 1：硬规则区是退化元凶，对比示例被淹没

消融结果确定：V2 (full) 59.3 与 V2-rules-only 58.7 几乎一致。退化完全来自硬规则区，对比示例在其中仅起到微弱的缓冲作用（+0.6 vs rules-only），远不足以证明其独立有效性。对比示例不跑第二条消融，它的独立价值需要重新设计实验才能公平评估。

### 发现 2：引文质量是最大受害者

引文从 2.59（V1）跌到 2.23（rules-only），跌幅 0.36。最可能的根因："禁止元描述 — 不要出现「根据提供的资料」等套话。直接回答问题，像人类一样说话"——模型可能把这条过度泛化为"不要标注来源"。8B 模型可能无法精确区分"元描述"和"引用标记"之间的语义边界，"像人类一样说话"的人类通常不会写 `[来源: N]`。

### 发现 3：整合质量再次下跌

整合从 2.73 跌到 2.53（rules-only，−0.20）和 2.60（full，−0.13）。硬规则区的"禁止逐篇罗列"不仅没有比 Phase 1 的温和约束更有效，反而因为整体 prompt 质量下降（引文崩塌的连带影响，或者硬规则区的负面情绪溢出），连 Phase 1 已经拿到的整合收益也侵蚀了一部分。D 级从 38 涨到 60，说明"禁止"式指令对这个规模的模型来说是反向刺激。

### 发现 4：唯一正向信号——相关性微涨、准确性未跌

即使在全面崩溃中，相关性和准确性都为正值——说明硬规则区确实让模型更聚焦问题本身、更少编造。但代价太大：为了 +0.08 的相关性增益，付出了 −0.36 引文的代价。

### 发现 5：Phase 1 有效 = 正面引导，Phase 2 失败 = 强制约束

将前两个 Phase 对比：

| | Phase 1 | Phase 2 |
|---|---|---|
| 核心策略 | 正面引导（分步指令 + 温和提醒 + 正面示例） | 强制约束（硬规则 + 禁止 + 惩罚声明） |
| 语气 | "你应该怎么做" + 轻微"不要" | "违反则不合格" + 强硬"禁止" |
| 约束位置 | 末尾（低优先级） | 开头（高优先级） |
| 结果 | 整合 +0.26，总分 +0.4 | 引文 −0.46，总分 −5.5 |

模式清晰：8B 对**正面指令**响应良好，对**负面惩罚性指令**过拟合。分步告诉它"怎么做"有效，拿不许做什么来威胁它反而崩溃。这符合中小模型的常见行为模式——有限的注意力会被高强度的负面情绪指令劫持，挤占实际任务的算力预算。

---

## 决策

1. **放弃硬规则区路线。** "禁止" + 惩罚声明的强制性负面约束不适合 8B 模型，会造成引文质量和整合质量的双重退化。不投入更多时间迭代硬规则区的措辞。

2. **对比示例单独保留测试价值。** 对比示例在 V2 (full) 中表现出微弱的缓冲效果，且其设计理念（正面引导）与 Phase 1 成功的方向一致。后续可作为 Phase 3 的一部分或在独立实验中测试。

3. **Phase 3 直接以 V1-full 为基座。** 分级拒答 + 查询类型判断的设计风格与 Phase 1 一致（正面引导），不引入任何负面惩罚性指令。
