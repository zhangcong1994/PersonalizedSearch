# exp-010 Phase 1 结果

> 实验目标：在分步整合指令（CoT）下，Qwen3-8B 的整合质量能否超越基线
>
> 实验类型：Prompt 工程，单变量消融，纯文本改动，无训练
>
> 核心结论：**整合质量 +0.26（2.47→2.73），远超成功标准（+0.13）。整合 4 分从 0 条首次突破到 11 条。thinking 模式带来额外收益：总分 67.7，整合 2.81，4 分整合 17 条。**
>
> 创建日期：2026-06-03

## Phase 1 Prompt 改动

在基线 prompt 基础上，仅做两处改动：

1. **新增「整合步骤」区块**（~130 字）：将"综合多篇资料"这个抽象指令拆为 4 个子步骤——提取关键点 → 合并重复 → 连接互补 → 识别矛盾。整理完成后按"核心结论 → 展开细节 → 标注分歧"输出。

2. **新增「避免以下行为」区块**（~50 字）：3 条温和负面约束——不要逐篇罗列、不要让同一信息点重复、多篇说同一件事用一句话概括。使用"不要"而非"禁止"，为 Phase 2 硬规则区留出强度递进空间。

其余全部与基线相同：角色设定、4 条核心原则（仅原则 2 末尾加了"具体做法见下方整合步骤"的引用）、回答结构指引、2 个 few-shot 示例。

## 分析

### 发现 1：分步指令有效释放了 8B 的整合潜力

整合质量 +0.26 是 Phase 1 成功标准（+0.13）的 2 倍。4 分整合从 V0 的 0 条突破到 11 条——分步指令确实教会了模型做更深层的跨文档整合，而不仅仅是"少罗列一些"。

1 分（逐篇罗列）从 32 条降到 19 条，降幅 41%。说明"步骤 1 提取关键点 → 步骤 2 合并重复"这条链路在大多数 case 上都生效了——模型从"全篇照搬"变成了"提取后再合并"。

### 发现 2：CoT 式 prompt 有准确性代价

准确性从 3.29 跌到 3.10（−0.19），F 级从 10 涨到 14。推理步骤拉长，模型在做跨文档推理时可能对某些事实做了不当的归并或泛化——"合并重复"时把不完全相同的信息当成了重复。这是 CoT 式 prompt 的已知副作用：推理链越长，信息保真度越低。

### 发现 3：thinking 模式与分步指令产生正向协同

这是 Phase 1 最重要的意外发现。基线状态下，8B thinking（60.5）总分微低于 non-thinking（60.9），仅整合（2.35 vs 2.27）和引文（2.53 vs 2.47）微超。但 Phase 1 prompt 下局势反转：

- thinking 总分 67.7，比 non-thinking 64.2 高出 3.5 分
- 整合 2.81（+0.08）、引文 2.69（+0.10）、准确性 3.24（+0.14）三维全面领先
- 整合 4 分达到 17 条（non-thinking 11 条）
- thinking 甚至修复了 non-thinking 的准确性下跌（3.10 → 3.24，回到接近 V0 水平）

**解释**：新 prompt 的外部化分步指令和 thinking 内部推理链在这一规模上不是互相冲突，而是互相促进。分步指令给了 thinking 一个清晰的推理框架，"内部思考 + 外部框架"比单独任一种方式都更有效。thinking 的内部推理还充当了事实校验层，降低了 CoT 失真的风险。

### 发现 4：thinking 的用户体验有代价

thinking 的用户体验从 non-thinking 的 3.42 跌到 3.15，是全场最低（甚至低于 V0 的 3.33）。可能原因：thinking 模式可能把内部推理痕迹泄露到了输出中——答案中混入了"思考过程"的残留，读起来不够干净。

### 发现 5：D 级信号矛盾（thinking 特有）

thinking 的 D 级从 38 反弹到 47（+9），但总分却比 non-thinking 高 3.5 分。这说明 thinking 在少数 case 上出了严重问题（可能过度分析导致答案冗长或偏离），但在大多数 case 上表现更优——优秀更优秀，差的也更差。后续需抽取 thinking 的 D 级 case 做定性分析。

## 决策

1. **Phase 2 在 non-thinking 上进行。** 硬规则区 + 对比示例的目标是进一步抑制"逐篇罗列"残存（仍有 19 条整合 1 分）和修复准确性的微跌。thinking 的对照安排在 Phase 4。

2. **thinking + Phase 1 的组合（67.7）值得持续关注。** 如果后续 Phase 能改善用户体验（当前 3.15），这个组合有潜力逼近 70 分。

3. **准确性下跌是后续 Phase 需要关注的风险信号。** Phase 2 的"禁止编造"硬规则和 Phase 3 的分级拒答可能对此有帮助——通过更明确的拒答边界减少模型在"资料不足"时的不当综合。
